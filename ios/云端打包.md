# 云端打包

Windows 上没有 Xcode，用云端 CI 编译。**不需要任何证书或 Secret。**

---

## 两种模式

| 模式 | 说明 | 耗时 |
|---|---|---|
| **compile-only** | 仅编译检查，日志输出全部编译错误 | 约 3–5 分钟 |
| **ipa** | 编译并导出无签名 IPA | 约 5–10 分钟 |

建议先跑 `compile-only`，把编译错误解决后再出 IPA。

## GitHub Actions

### 设置

**1. 推代码到 GitHub**

```bash
cd C:/Users/Administrator/WorkBuddy/2026-10-20-09-21-18
git init
git add .
git commit -m "NetaL iOS"
git remote add origin https://github.com/你的用户名/你的仓库.git
git push -u origin main
```

> **公开仓库** → macOS runner 免费不限量
> **私有仓库** → 免费账号约 200 分钟/月（macOS 按 10 倍计）

**2. 运行**

仓库 `Actions` 标签 → 左侧选 `Build IPA` → 右上 `Run workflow` → 选模式 → 点绿按钮。

**3. 看结果**

- 编译错误直接显示在构建页面，日志里列全
- 构建摘要（Summary）区有汇总
- IPA 模式的话，在页面底部 `Artifacts` 下载 `NetaL-ipa`

配置文件：`.github/workflows/build-ipa.yml`

## Codemagic

不想用 GitHub 也可以。

**1. 注册**

访问 https://codemagic.io（免信用卡，每月 500 免费分钟）

**2. 添加应用**

`Add new app` → 选 GitHub → 选仓库 → 类型选 iOS

**3. 启动构建**

配置文件会自动识别（`ios/.codemagic/codemagic.yaml`），点 `Start build`。

产物在 `Artifacts` 区。

## ⚠️ 关于无签名 IPA

导出的 IPA **没有签名，无法直接安装到 iPhone**。

iOS 要求所有应用都必须有有效签名才能安装，这是系统级的强制要求，没有绕过方式。无签名 IPA 的用途是：

- 验证构建流程是否跑通
- 检查资源、Bundle 配置是否正确
- 确认 Release 模式下没有编译错误

想真正装到手机上，之后需要配签名。你可以自己签名——但那需要 Apple Developer Program（付费 $99/年），在 Apple Developer Portal 建 App ID 和描述文件。

如果只是先看看能不能跑通，用 `compile-only` 模式就够了。

## 优先跑编译检查

我在 Windows 上只做了括号配平和语法结构检查，**没有 Swift 编译器验证过 16 个 Swift 文件**。

云端编译会一次性暴露所有问题：

- 类型不匹配
- iOS 16 vs 17 的 API 差异
- actor / MainActor 隔离问题
- SwiftUI 视图构造的运行时问题

这一步零成本、零配置，不需要证书。**拿到错误日志发我，我改。**

常见的可能问题：

| 类型 | 典型表现 |
|---|---|
| actor 隔离 | `Main actor-isolated property can not be referenced from a Sendable closure` |
| iOS 版本 | `available(iOS 17.0, *)` 缺失，部署目标是 16.0 |
| SwiftUI | `@MainActor` 缺失导致运行时崩溃 |
| Keychain | 强制解包 `item as! SecKey?` 在真机可能失败 |

## 常见问题

**Q：编译报错找不到某个类型**

如果报 `cannot find 'xxx' in scope`，先看是不是文件没加进 target。
`project.yml` 里的 sources 配置是 `NetaL` 整个目录，正常不会漏。

**Q：xcodegen 装不上**

云端环境是 macOS，`brew install xcodegen` 应该能装。
如果失败，检查是不是配置写错了路径。

**Q：想每次推送自动编译**

把 workflow 的触发条件改成：

```yaml
on:
  push:
    branches: [main]
  workflow_dispatch:
```

不过建议先用手动触发，编译错误多的时候自动跑会浪费额度。

**Q：能上传 TestFlight 吗**

能，但需要 `GH_PAT`（Personal Access Token，权限要 App Manager）
和付费开发者账号。当前配置没包含这条。
